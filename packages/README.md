# packages/ 目录说明

## 📦 概述

`packages/` 目录是 daoda-component 项目的核心包目录，包含所有可独立发布和维护的包。

## 📁 目录结构

### 🎨 config/ - 配置包

**作用**: 提供全局配置管理功能

- **功能**: 主题配置、全局设置、样式变量等
- **依赖**: Vue 3
- **使用场景**: 为整个组件库提供统一的配置管理

### 🛠️ utils/ - 工具包

**作用**: 提供通用工具函数和辅助方法

- **功能**: 防抖、节流、格式化、验证等工具函数
- **依赖**: 无外部依赖
- **使用场景**: 为组件库提供通用工具函数

### 🧩 components/ - 组件包目录

包含所有 UI 组件的实现

#### button/ - 按钮组件

- **功能**: 封装 Element Plus 按钮，提供增强功能
- **特性**: 节流、防抖、主题定制
- **依赖**: Vue 3, Element Plus

#### select/ - 选择器组件

- **功能**: 封装 Element Plus 选择器，支持国家选择器
- **特性**: 国家数据、搜索、过滤
- **依赖**: Vue 3, Element Plus

### 🎯 demo/ - 主演示包

- **功能**: 提供组件库的主要演示和测试环境
- **用途**: 开发时测试组件功能
- **依赖**: 所有其他包

## 🔧 开发规范

### 包结构

每个包都应该包含：

- `src/` - 源码目录
- `dist/` - 构建输出目录
- `package.json` - 包配置
- `vite.config.ts` - 构建配置
- `tsconfig.json` - TypeScript 配置

### 命名规范

- 包名格式: `daoda-{功能名}`
- 组件名格式: `Daoda{组件名}`
- 文件名格式: `{组件名}.vue`

### 依赖管理

- 使用 `workspace:*` 引用内部包
- 外部依赖放在 `dependencies` 或 `peerDependencies`
- 开发依赖放在 `devDependencies`

## 📋 开发流程

1. **创建新包**: 在 `packages/` 下创建新目录
2. **配置包**: 创建 `package.json` 和构建配置
3. **开发组件**: 在 `src/` 目录下开发
4. **测试**: 在 `demo/` 中测试功能
5. **构建**: 使用 `pnpm run build` 构建
6. **发布**: 使用 Lerna 发布包
